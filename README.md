# Launch Lab

数秒で心をつかむ。  
見て、試して、実装できるオープニング集とコミュニティ。

## 目的
Launch Lab は、HTMLで試せる数秒オープニング演出を入口に、
React / Flutter / Expo / Android などへの実装導線、
作品投稿、Discordコミュニティ、商品販売、個別移植依頼までつなぐ
作品ギャラリー付き実装コミュニティをつくるプロジェクトです。

## ディレクトリ
- `docs/` 企画・要件・ルール
- `web/` サイト本体
- `previews/` HTMLプレビュー集
- `assets/` 素材
- `community/` Discord関連
